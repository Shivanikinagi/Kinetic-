# Reach

## Who it is for

- **AI agents and their builders** running batch labelling: classification, extraction and tagging over thousands of items. They want cheaper GPUs than hosted APIs, without trusting whoever owns the GPU.
- **People with idle GPUs** (gaming PCs, small labs) who can sell inference per chunk without signing up to a platform. They post a bond and an Arkiv offer.

## Can they try it today

- `npm run live -- --serve` and the dashboard run it on the real networks: providers doing their work on 0G Compute, payments and slashing on Hedera, offers, claims and reputation on Arkiv.
- `npm run setup:testnet && npm run live` runs it on Hedera testnet, Arkiv (Rabdi), Swarm and 0G (see the README).
